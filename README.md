# OC-Defense-Depth-Chart
The OC Eagles palette is royal blue, gold, and white. Right now the three position groups use teal/blue, purple, and burnt orange — none of which relate to the school. Let me rethink them around that palette while keeping the three groups visually distinct and readable.

Design approach:

	•	Secondary (DBs) — Royal blue. This is the school’s primary color, so the most prominent group gets it.
	•	Linebackers — Gold/amber. The school’s secondary accent color. Warm, distinct from blue.
	•	D-Line — Charcoal/slate. A strong neutral that contrasts with both blue and gold without clashing, gives the big guys an imposing look.
